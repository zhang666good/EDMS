# /v1/chat/completions 接口详细日志说明

## 📋 功能说明

已为 `/v1/chat/completions` 接口添加了详细的请求、响应和认证信息打印，方便调试和监控。

---

## 🔍 打印的信息

### 1. **请求信息** 📨
- ⏰ 请求时间
- 📋 Model名称
- 👤 用户ID
- 🌊 是否流式响应
- 💬 消息内容（前100字符预览）
- 📎 Context ID（如果有）
- 📄 MD Content（如果有）

### 2. **认证信息** 🔐
- ✅ Authorization头（完整或前50字符）
- 🔑 提取的Token（前30字符）
- ⚠️ Token格式警告（如果非Bearer）

### 3. **数据库验证** 🗄️
- 🔍 查询的API Key（前30字符）
- ✅/❌ 验证结果
- 👥 识别的角色
- 📝 用户UID
- 📛 用户姓名
- 📱 手机号

### 4. **处理信息** 🎯
- 🎯 解析的Agent别名
- 📝 构建的Query长度

### 5. **响应信息** 📤
- ✅ 状态
- 📊 回答长度
- 💬 回答预览（前200字符）

### 6. **错误信息** ❌
- Dify网关错误
- 认证失败原因

## 🔧 使用场景

### 1. 调试认证问题
查看认证头和数据库验证结果，快速定位问题：
- Token是否正确传递
- API Key是否在数据库中
- 角色识别是否正确

### 2. 监控用户行为
记录每次请求的：
- 哪个用户（UID、姓名）
- 什么时间
- 访问了哪个Agent
- 问了什么问题

### 3. 性能分析
通过时间戳和Query长度，分析：
- 请求频率
- 问题复杂度
- 响应时间

### 4. 安全审计
检测异常行为：
- 频繁的认证失败
- 无效的API Key尝试
- 越权访问尝试

## 📝 自定义日志级别

如果需要调整日志详细程度，可以修改代码中的打印语句：

### 简化版（只打印关键信息）
```python
print(f"[AUTH] Role: {role}, User: {user_info.get('name')}")
print(f"[RESPONSE] Length: {len(final_answer)} chars")
```

### 详细版（当前实现）
包含所有详细信息，适合开发和调试。

### 静默版（关闭日志）
注释掉所有 `print()` 语句。

---

## ⚠️ 注意事项

### 1. 敏感信息脱敏
当前实现会对长字符串进行截断：
- Authorization头：超过50字符显示 `...`
- Token：超过30字符显示 `...`
- 消息内容：超过100字符显示 `...`
- 回答预览：超过200字符显示 `...`

### 2. 生产环境建议
在生产环境中，建议：
- 使用logging模块替代print
- 将日志写入文件
- 设置日志轮转（避免文件过大）
- 脱敏更多敏感信息

### 3. 性能影响
大量打印可能影响性能，建议：
- 开发环境：开启详细日志
- 测试环境：开启关键日志
- 生产环境：仅记录错误或关闭

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 发送测试请求
```bash
curl -X POST 'http://127.0.0.1:8000/v1/chat/completions' \
  -H 'Authorization: Bearer edms-business-analyst-test5678' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "edms-deep-insight",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false,
    "user": "test_user"
  }'
```
