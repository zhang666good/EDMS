# 上交所公告自动导入功能

## 📖 功能说明

此功能可以自动从上交所网站搜索公告，下载 PDF 文件，并批量导入到指定的知识库中。

## 🚀 使用步骤

### 1. 访问管理页面

打开浏览器访问：
```
http://localhost:8000/admin
```

### 2. 登录系统

使用管理员账号登录（默认凭据见 `.env` 文件）

### 3. 进入上交所公告导入页面

在左侧导航栏点击 **"📰 上交所公告导入"**

### 4. 搜索公告

填写搜索参数：
- **关键词**（必填）：例如 "年度报告"、"财务报表"、"利润分配"
- **每页数量**：每次搜索返回的结果数（默认 10，最大 50）
- **页码**：分页查询（从 0 开始）

点击 **"🔍 搜索公告"** 按钮

### 5. 选择目标知识库

在搜索结果区域：
1. 从下拉列表中选择要导入的知识库
2. 勾选需要导入的公告（支持全选/取消全选）
3. 可以点击 "查看原文" 预览公告内容

### 6. 导入到知识库

点击 **"📥 导入选中项"** 按钮

系统会：
1. 自动下载选中的 PDF 文件
2. 上传到指定的知识库
3. 显示导入结果统计

## ⚙️ 技术实现

### 后端服务

**文件**: `app/services/auto_into_knowledge.py`

包含两个主要函数：

1. **`main(args)`** - 搜索上交所公告
   - 调用上交所搜索引擎 API
   - 解析 JSONP 响应
   - 提取公告元数据（标题、URL、股票代码等）

2. **`download_and_upload_to_knowledge(args)`** - 下载并导入
   - 遍历搜索结果
   - 下载 PDF 文件到临时目录
   - 调用 Dify API 上传到知识库
   - 清理临时文件

### API 接口

**文件**: `app/api/backend.py`

1. **POST `/api/v1/backend/sse/search`** - 搜索公告
   ```json
   {
     "keyword": "年度报告",
     "page": 0,
     "limit": 10,
     "searchMode": "fuzzy",
     "orderByKey": "score",
     "orderByDirection": "DESC",
     "spaceId": 3
   }
   ```

2. **POST `/api/v1/backend/sse/import-to-dataset`** - 导入到知识库
   ```json
   {
     "search_results": [...],
     "dataset_id": "知识库ID"
   }
   ```

### 前端界面

**文件**: 
- `app/web/index.html` - 页面结构
- `app/web/app.js` - JavaScript 逻辑

主要功能：
- 搜索表单
- 结果展示表格
- 复选框多选
- 知识库选择器
- 导入进度反馈

## 📝 注意事项

### 1. 环境配置

确保 `.env` 文件中配置了 Dify 相关参数：
```env
DIFY_BASE_URL=http://123.207.72.88:8088/v1/
DIFY_API_KEY=dataset-c6isoIYCm9MhwW9eOO25aKGF
```

### 2. 文件格式

- 仅支持 PDF 格式的公告
- 部分公告可能没有提供下载链接（会被标记为失败）

### 3. 性能考虑

- 建议每次导入不超过 20 个文件
- 每个文件约需 2-5 秒处理时间
- 大批量导入建议在非高峰期进行

### 4. 错误处理

导入失败的可能原因：
- 网络连接问题
- PDF 链接失效
- 知识库 ID 无效
- Dify API 异常

失败的项目会在控制台输出详细错误信息

## 🔧 故障排查

### Q1: 搜索无结果
**A**: 
- 检查关键词是否正确
- 尝试更换搜索词
- 确认上交所搜索引擎正常

### Q2: 导入失败
**A**:
- 检查 Dify 配置是否正确
- 确认知识库存在且可访问
- 查看后端日志错误信息

### Q3: 导入速度慢
**A**:
- 检查网络连接
- 减少单次导入数量
- 确认 Dify 服务响应正常

## 📊 示例场景

### 场景 1: 收集某公司年度报告

1. 搜索关键词："600644 年度报告"
2. 选择最近 3 年的报告
3. 导入到"上市公司年报"知识库

1. 搜索关键词："电力行业"
2. 按时间排序
3. 批量导入近半年的公告

## 🎯 最佳实践
